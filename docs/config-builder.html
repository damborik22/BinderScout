BinderScout config builder

Fills in a config.json for binderscout configure --config <file>. Nothing is uploaded; the page runs entirely in your browser.

This page is generated from configurator.py by tools/make_config_builder.py. Do not edit it by hand — a test fails when the two disagree, which is how a second list of tools and flags is kept from drifting out of step with the real one.
