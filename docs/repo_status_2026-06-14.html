Evaluation layer — binder-compare pipeline

target + tool outputs └─ extract one sequence-extractor per tool → FASTA + native-metrics sidecar └─ refold Boltz-2 (Mosaic venv) + AF3 (binder-eval-af3) [canonical] Protenix (24 GB) + ESMFold2 (lightweight) [optional] └─ rank TWO-STAGE: stage 1 screen = max(engine iPTMs), keep top 50% stage 2 rank = mean(engine iPTMs) (precision) └─ report HTML + metrics.csv (native metrics ride alongside)

Gate / screen metric: ESMFold2 chain_iptm_interface — the symmetric mean of the two directional pair_chains_iptm off-diagonals. On the ProteinBase 4-target benchmark it is the single strongest binder discriminator (macro AUC ≈ 0.745), and it runs off the Spark-locked GPU.

New — binder-compare autosize (adaptive sampling controller)

Decides "do we have N independent good designs yet?" and, if not, how many more to draw.

  • Counts independent backbones, not sequences — collapses MPNN/cycle variants to one entry per design_group before counting.
  • Tier-aware gate — --tier permissive 0.70 / default 0.75 / strict 0.80 (interface-iPTM convention); --threshold overrides.
  • Equal across tools — every tool driven to the same --n-target; per-tool --budget-cap lets hard tools settle for fewer (never loops forever).
  • Two modes — single-shot verdict, or --loop (generate → refold → decide) wiring --generate-cmd / --refold-cmd.
  • Next-batch size = ceil((target − have)/yield × 1.2); cold start explores MIN_PROBE.
