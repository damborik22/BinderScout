Five tools are pre-checked: BindCraft, BoltzGen, Mosaic, Evaluator, RFD3 (install.sh:558–565). PXDesign, Proteina-Complexa and Protein-Hunter start off. Confirming with nothing selected prints No tools selected. Select at least one. and reprints.

Gap in the click path. The menu offers 8 items. Three installable targets are missing from it entirely and reachable only via --tool: ESMFold2 (the documented default refold engine), AF3, and SoluProt. So a mouse-and-menu user cannot install the default refold engine at all — they must fall back to bash install/install.sh --tool esmfold2.

Every one of those mid-install questions defaults to no — the safe answer, and what makes a repeat install non-destructive. confirm() only accepts y/yes as yes; n, no and bare Enter all mean no, and there is no [Y/n]-style prompt anywhere in the installer.

Only BindCraft, BoltzGen and Mosaic ask anything mid-install. Evaluator (install.sh:1115–1197) and RFD3 (:1893–1945) — both pre-checked — run start to finish unattended, as do PXDesign, Protein-Hunter, AF3, ESMFold2 and SoluProt. Long steps show only a spinner and print the last 30 log lines on failure (install.sh:244–272); everything is tee'd to install.log.

Three things people expect here and will not find, having been checked against the source: there is no CUDA-version question (CUDA_VERSION defaults to 12.4 and is settable only with --cuda), no disk-space or GPU preflight before ~60 GB of downloads, no AF2-weights-path prompt (weights are auto-symlinked from bindcraft-tools/af2_params), and no standalone-vs-system-conda question — that is auto-detected silently, and the only thing you see is the warning line above.

This is the screen --yes overrides. confirm() returns true unconditionally under --yes (install.sh:282), so --tool all --yes answers yes to "Remove and reclone?" — deleting BindCraft/params/*.npz, ~4 GB of AF2 weights. The click path is the safe one here; the documented flag path is the destructive one. (Finding F11.)

Choosing [2] Amino acid sequence in Step 2 opens a sub-flow (:2732–2808): it asks How would you like to predict the structure? with [1] Predict locally with Boltz-2 (GPU recommended, ~2-5 min) or [2] Use AlphaFold 3 Server, takes the sequence, and either folds it or walks you through the AF3 web server and asks for the downloaded file. Step 3 is where finding F1 bites. The green ✓ Auto-extracted sequence for chain A line will still say "chain A" while showing a different chain's sequence. Read the residue count on that line — it is the only signal you get.

Why the BoltzGen column order matters. designed_sequence holds only the designed residues. Header = >{binder_id} + two spaces + key=value tags joined by two spaces. A sidecar sequences_native_metrics.csv is written next to it (cli/extract.py:151) carrying the per-tool native metrics above — the FASTA itself only transports id, sequence, source and length.

Duplicates are removed here by default (cli/extract.py:87–98, first occurrence wins, prints Removed N duplicate sequence(s)). That matters downstream: merger.py joins on sequence with no dedup of its own, so --keep-duplicates lets one design fan out into several report rows. (Finding F6.)

Driving it entirely by menu — the practical recipe

  1. bindmaster → Install tools → toggle what you want → Enter → y. Answer no to every "Remove and reclone?" if you already have a working install.
    Then, unavoidably by flag, for the default refold engine: bash install/install.sh --tool esmfold2 — the menu cannot reach it.
  2. bindmaster → Configure run → walk the 7 steps. Prefer a .pdb target over .cif (F1), and check the residue count on the ✓ Auto-extracted sequence line.
  3. Answer no to "Run the pipeline now?" if you enabled RFD3 or Protein-Hunter, then run bash runs/<name>/run_all.sh — it is the only launcher that covers all seven. If Mosaic is enabled, run run_mosaic.sh first (F8).
  4. bash runs/<name>/run_evaluate.sh — not the TUI's "Evaluate results" and not the evaluate shortcut, both of which error out (§5). Add --rfd3 runs/<name>/rfd3 to the extract call yourself if RFD3 ran.
  5. Open runs/<name>/evaluate/report/report.html. Sort on consensus_iptm_mean and check consensus_iptm_n before trusting a top row (F5).
